# Fallstudie zu IPWA02-01 – Programmierung von industriellen Informationssystemen mit Java EE

Dieses Repository enthält meine Umsetzung der **GhostNet-Fishing-Anwendung** im Rahmen der Fallstudie für das Modul IPWA02-01.

## Funktionen

- Erfassung von Geisternetzen mit den zugehörigen Informationen
- Persistente Speicherung der Geisternetz-Meldungen in einer MySQL-Datenbank
- Verwaltung von Geisternetzen und zugehörigen Personen
- Umsetzung der Benutzeroberfläche mit JavaServer Faces (JSF)
- Verarbeitung und Speicherung der Daten mit Java Persistence API (JPA)
- Umsetzung der Fallstudie mit Java EE und Maven

## Nutzung

1. Das Repository klonen oder als ZIP herunterladen.
2. Das Maven-Projekt in einer Java-EE-fähigen Entwicklungsumgebung, beispielsweise Eclipse, importieren.
3. Die benötigte MySQL-Datenbank konfigurieren und die erforderlichen DataSources im TomEE-Server einrichten.
4. Das Projekt über Maven erstellen und auf einem geeigneten TomEE-Server bereitstellen.
5. Die Anwendung im Browser öffnen.

## Technologien

- Java
- Java EE
- JavaServer Faces (JSF)
- Contexts and Dependency Injection (CDI)
- Java Persistence API (JPA) mit Apache OpenJPA
- MySQL
- Apache Maven
- Apache TomEE
